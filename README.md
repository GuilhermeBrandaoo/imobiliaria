# 🏡 Alto Padrão Imóveis

Projeto de uma landing page moderna para uma imobiliária de alto padrão, desenvolvido com HTML, CSS e JavaScript puro.

O objetivo deste projeto foi praticar desenvolvimento front-end, criação de layouts modernos, responsividade e manipulação do DOM com JavaScript.

O design visual do projeto foi desenvolvido com auxílio de Inteligência Artificial, enquanto toda a estrutura, organização, personalização e lógica foram estudadas, adaptadas e implementadas durante o processo de desenvolvimento.

# ⚙️ Funcionalidade do formulário

O formulário captura:

- Nome
- Telefone
- Interesse do cliente

Após o preenchimento, o JavaScript cria automaticamente uma mensagem personalizada e abre o WhatsApp para contato direto com a imobiliária.
